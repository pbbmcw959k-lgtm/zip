# Zip — démo mobile

Démo 100 % côté navigateur de **Zip**, un coffre-fort de documents personnel avec un assistant.
Toutes les données restent dans le navigateur (IndexedDB). Documents de démonstration **fictifs**.

- Import de photos et de PDF ; texte des PDF via pdf.js, OCR en français via tesseract.js (chargés à la demande depuis jsDelivr)
- Classement et extraction (catégorie, date, émetteur, montant, garantie, médecin) par des règles françaises sur l'appareil
- Assistant par mots-clés : retrouver un document, totaux, garanties
- PWA installable (iPhone : Safari → Partager → Sur l'écran d'accueil)

Pas de serveur ni de compte, pas de réception d'e-mails dans cette version.
